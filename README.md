# AuraGarden · 流水花园

基于 AI + AR 的现实增强花园游戏。给定 GPS 定位和当前位置的照片,自动生成包含真实植被特征的花园全景,分析土壤与水分;启动游戏时间轴后,依据天气预报模拟真实植被的生长,并预测未来植被状态。玩家可以自由调整花园布局与植物种类,体验创造和维护花园的乐趣。

## 游戏特点

- **现实锚定**:以 GPS 位置和现场照片为输入,花园与真实环境相关联。
- **场地分析**:自动估算土壤类型、pH、湿度、肥力和日照;给出种植建议。
- **全景花园**:照片作为环景背景,周边植被按场地生成,地面颜色随土壤与湿度变化。
- **天气驱动的生长模拟**:前 14 天使用天气预报,之后用气候估算,共推演 90 天。每种植物有各自的温度、水分、光照、pH 需求。
- **未来预测**:时间轴可播放或拖动,预览任意一天的植物成熟度、健康度和土壤湿度。
- **现实日历 + 快进预测(规划中)**:花园随真实日期每天推进,使用真实天气,逐日看到变化;也可以把时间轴快进到未来预览模型预测的结果(预览不会改变实际花园)。一段时间没打开游戏,下次打开会把期间真实发生的变化全部补上(真实天气、季节与日照、动物与病虫害、你已安排的操作),效果和一直开着一样,并告诉你离开期间发生了什么。v1 没有货币或精力限制。
- **回放(规划中)**:选一段时间范围,把期间的天气、你的操作、动物来访、病虫害和植物的变化按时间重新播放,可倍速、逐日、跳到事件,并显示每件事的原因。离开一段时间后,可以从"离开报告"一键回放这段时间。
- **历史年份选项(规划中)**:创建花园时可以选择一个过去的年份(如 2012),花园在当年当地的真实天气下运行,时间可暂停、逐日或倍速,快进即生效;创建后整年天气已保存,可离线玩。
- **自由创造**:8 种植物(薰衣草、向日葵、玫瑰、绣球、番茄、草坪、橡树、樱花树);点击地面种植,点击植物铲除;调色板显示每种植物对当前场地的适宜度。改动布局后自动回到"今天"并重新预测。
- **园艺操作(规划中)**:像真实园丁一样浇水、除草、修剪、采收、换土、改良土壤、移栽、防霜遮阳等;操作可以安排在时间轴上的某一天,预测会按计划推演;可设置周期规则(如"雨后跳过浇水")。
- **生态互动与本地动物(规划中)**:植物之间会互相遮荫、争水争肥、传播病虫害;所在地常见的小动物(传粉者、兔鹿、蜗牛、鸟类等)会来访,有的帮忙、有的啃食。花园可能变差甚至植物死亡,但原因会被解释、可以补救,时间轴能提前预览风险;另有休闲模式。
- **自定义物种(规划中)**:8 种植物是游戏自带的默认物种;玩家还可以提供图片、文字描述,或官方/经验证的物种来源网址来添加自己的物种,确认识别结果和参数后即可种植。解析需要联网,保存后可离线使用。
- **离线可玩,联网同步**:没有网络时也能编辑布局、播放时间轴和查看预测;联网后自动同步到云端,并用真实天气预报和 AI 分析校正结果(规划中)。
- **AR(规划中)**:手机端通过 Unity AR Foundation(ARKit / ARCore)把同一场景叠加到现实画面;桌面版没有 AR。
- **Steam 发布(规划中)**:桌面版计划上架 Steam,支持 Steam Cloud 存档、成就和 Steam Deck。桌面版没有 GPS 和 AR,位置手填,照片从文件导入。

## 当前状态

技术方向:正式客户端将使用 Unity(手机 AR + 桌面/Steam),尚未开始开发;目前仓库中的 Web + Three.js 版本是原型,用于验证玩法和生长模型。原型**AI 场地分析与天气均为 mock 数据**(接口已隔离,可替换为真实服务)。详见 [docs/development_plan.md](docs/development_plan.md) 与 [docs/versions.md](docs/versions.md)。

## 运行

```
npm install
npm run dev        # 开发服务器
npm run typecheck  # 类型检查
npm run build      # 构建
```

操作:输入经纬度(或点 GPS 定位)→ 可选上传照片 → 生成花园 → 在左侧选择植物并点击地面种植 → 用底部时间轴播放/拖动查看未来。拖拽旋转视角,滚轮缩放。
